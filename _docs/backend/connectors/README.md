## Overview

This directory contains connector implementations and the small set of supporting modules that let the application interact with external distribution providers. At the root level there is a concrete connector implementation routenote.py which implements a RouteNote connector as a Distributor subclass. Also present (but not documented here) are __init__.py and base.py which provide package initialization and the shared base classes/interfaces that connector implementations extend.

Together, these files form a focused area of the backend responsible for adapters between the application's distribution orchestration and specific third-party distributors. base.py defines the Distributor base class and common expectations; individual connector modules such as routenote.py implement those expectations to provide provider-specific behavior. __init__.py wires package exports and may be used by the application to discover available connectors.


### File Organization

Files are organized by connector feature: base.py defines the shared Distributor abstraction, concrete connector modules (e.g., routenote.py) implement that abstraction, and __init__.py exposes/connects them for package-level import. This keeps provider-specific logic isolated per module and the shared contract in a single place.
