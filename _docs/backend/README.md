## Overview

This directory hosts the core backend components used by the Zi service. At the root level it includes three documented Python modules: main.py implements the HTTP API surface for the Zi service (using FastAPI as noted in the file purpose), pipeline.py coordinates an audio generation and packaging pipeline that produces multi-section musical pieces, stitches segments into a single master of at least 180 seconds, performs licence and model-spec checks, and prepares a RouteNote-compatible release package, and media.py provides utilities for preparing audio and cover art assets for distribution. These three modules together provide the primary runtime behavior: main.py exposes endpoints to trigger or query work, pipeline.py performs the orchestration of generation and packaging tasks, and media.py handles the low-level preparation of audio and visual assets required for releases.


### File Organization

Files at the root are organized by responsibility: main.py is the HTTP entry point, pipeline.py encapsulates orchestration and business logic for audio generation and packaging, and media.py contains helper utilities for asset preparation. Additional support scripts and connectors exist alongside these core modules (listed but not documented here) to support containerization, testing, and external integrations.
